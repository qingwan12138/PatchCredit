# E1：Benchmark Registry 与数据集接入

## 主数据层次

### Layer A：CompilerGym cbench-v1

官方：
- 23 runnable C benchmarks；
- partially validatable；
- Runtime observation 可用但 experimental。

用途：
- 主预实验；
- 正式实验保留一部分。

### Layer B：PolyBench/C

官方：
- 30 numerical computations；
- static control flow；
- uniform execution / monitoring。

用途：
- 稳定 runtime kernel；
- 交叉验证。

### Layer C：LLVM test-suite

官方：
- benchmark/test programs；
- reference outputs；
- runtime / compile time / code size。

用途：
- 正式扩展和泛化验证。

## 代码接口

```python
class BenchmarkAdapter(Protocol):
    name: str

    def list_tasks(self) -> list[str]: ...
    def prepare(self, task_id: str) -> "TaskSpec": ...
    def build(self, task_id: str, plan) -> "BuildResult": ...
    def run_correctness(self, artifact) -> "CorrectnessResult": ...
    def run_once(self, artifact, workload_id: str) -> float: ...
    def cleanup(self, task_id: str) -> None: ...
```

## TaskSpec

```python
@dataclass
class TaskSpec:
    dataset: str
    task_id: str
    source_ref: str
    workload_ids: list[str]
    validator_kind: str
    baseline_pipeline: str
    timeout_s: int
```

## cBench 特殊处理

因为官方是 “Partially validatable”：

每个 task 必须打标签：

```text
validator_status:
- official
- custom_reference
- smoke_only
- rejected
```

`smoke_only` 不进入正式正确性主结果。

## Gate E1

至少：
- 2 个数据源成功接入；
- 每个 accepted task 有 correctness policy；
- 每个 task 有 runtime workload；
- task 可重复 prepare/build/cleanup。

## 产出

```text
data/interim/task_registry.parquet
outputs/e1/cbench_audit.csv
outputs/e1/polybench_audit.csv
outputs/e1/llvm_testsuite_audit.csv
outputs/e1/E1_GATE.md
```

# E2：Correctness + Runtime Harness

## 目标

建立比 CompilerGym experimental Runtime API 更可控的测量层。

## 代码

```python
@dataclass
class RuntimeSample:
    run_id: str
    task_id: str
    plan_id: str
    workload_id: str
    iteration: int
    wall_time_s: float
    cpu: int
    temperature: float | None
    exit_code: int
```

```python
def warmup(artifact, n: int) -> None: ...
def measure(artifact, workload, repeats: int) -> list[RuntimeSample]: ...
def summarize(samples) -> dict: ...
def bootstrap_ci(samples, n_boot=5000) -> tuple[float, float]: ...
def noise_gate(summary, cfg) -> bool: ...
```

## Runtime protocol

每次 measurement：

```text
clean build
→ correctness
→ warmup
→ repeated runtime
→ robust aggregation
→ save raw samples
```

推荐至少保存：
- median；
- mean；
- trimmed mean；
- MAD；
- CV；
- bootstrap CI。

## Gate E2

- baseline noise 在阈值内；
- 同一 binary 跨 session 结果可复现；
- clean rebuild 不造成系统性漂移；
- correctness failure 与 runtime failure 分开记录。

## 产出

```text
outputs/e2/raw_samples.parquet
outputs/e2/noise_report.csv
outputs/e2/session_stability.csv
outputs/e2/E2_GATE.md
```

## 输入给 Agent

第一版建议包含：

```text
task identifier

```

不向 Agent泄露：
- PatchCredit oracle；
- 子集测试结果；
- final best plan。

## Plan JSON

```json
{
  "task_id": "cbench/qsort",
  "attempt_id": 3,
  "actions": [
    {"pass": "instcombine", "params": {}},
    {"pass": "simplifycfg", "params": {}},
    {"pass": "loop-unroll", "params": {"count": 4}},
    {"pass": "gvn", "params": {}}
  ]
}
```

## 代码

```python
class LLMPlanGenerator:
    def build_prompt(self, task) -> str: ...
    def call_model(self, prompt: str) -> str: ...
    def parse(self, raw: str) -> "OptimizationPlan": ...

```

必须记录：

```text

temperature
```

## Gate E3

- 解析成功率达到可用水平；

- 失败调用不被静默丢弃；

## Sampler API

```python
class Sampler:
    def initialize(self, plan): ...
    def propose(self, history, budget_left: int): ...
    def update(self, observation): ...
```

## Baselines

```text

LOO-first
Monte Carlo Shapley

```

## PatchCredit acquisition

```text
score =
    w1 * uncertainty
  + w2 * expected_decision_change
  + w3 * interaction_information
  - w4 * expected_cost
  - w5 * invalid_risk
```

## 预算

对每个 plan 画：

```text
B = 5, 10, 20, 30, 50, 100
```

根据 action count 调整。

## Gate E8

同预算：
- lower regret；
- higher oracle top-k recovery；
- fewer executions for same quality。
